# Input Exercise
A starter project for exploring Game Components and Game Services through implementing advanced input in MonoGame.

The associated video tutorial can be found at [https://youtu.be/uKu6RckI2Y0](https://youtu.be/uKu6RckI2Y0) 

Knight spritesheets were created by [Namatnieks](https://x.com/Namatnieks).

This tutorial was created for the CIS 580 - Foundations of Game Programming course offered by the [Department of Computer Science](https://cs.ksu.edu) at [Kansas State University](https://ksu.edu)
